.accordion

Bootstrap 5.3 CSS variables like --bs-primary, --bs-success, and --bs-body-bg are pointed directly to Tailwind v4 oklch() tokens defined in :root.

No compiler required. It works directly with the standard Bootstrap 5.3.9 CDN stylesheet and pure CSS custom properties.

Using Tailwind slate-50 surfaces, crisp #ffffff cards, and slate-200 hairline borders delivers clean visual clarity across data-dense applications.

21. Scrollspy

Scroll inside the light box on the right to watch the linked navigation update automatically.

1. Introduction 2. OKLCH Scale 3. Light Surfaces 4. Deployment

1. Introduction

Scrollspy automatically updates Bootstrap navigation links based on scroll position inside this container. Try scrolling down smoothly to see each item activate in your active Tailwind accent color.

2. OKLCH Scale

Tailwind CSS v4 uses perceptually uniform OKLCH colors so step 600 across Indigo, Emerald, Rose, and Sky maintains balanced visual weight on light backgrounds.

3. Light Surfaces

Combining pure white elevated cards over Slate-50 page canvases provides subtle depth without needing heavy drop shadows.

4. Deployment

Because all overrides are pure CSS custom properties, your bundle stays tiny and requires zero build pipeline changes.
